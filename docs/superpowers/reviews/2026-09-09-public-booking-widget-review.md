## Исправления по результатам ревью

- Восстановленная запись без сохранённого Telegram-перехода снова получает
  серверный статус. Возврат фокуса или видимости вкладки запускает обновление.
  Привязка мессенджера сама по себе не считается подтверждением.
- Запоздалый ответ от другой записи не заменяет текущую карточку.
- Сервер возвращает фактическую привязку Telegram после действий с карточкой
  и не выпускает новый переход для уже привязанной записи.
- Выдача перехода и список доступных каналов одинаково проверяют настройку
  Telegram: невалидное имя бота не создаёт неработающую кнопку.
- Возврат к выбору времени восстанавливает выделенное занятие; UTM-параметры
  не создают отдельный черновик той же записи.
- На узких экранах адрес филиала получает отдельное место от действия смены
  филиала. Число колонок возраста зависит от доступной ширины, сохраняя область
  нажатия не менее 44×44.
- Убрано повторение сообщения о подключении Telegram. Сценарии браузерных
  тестов учитывают «Новую запись» и восстановление уже отправленной записи.
