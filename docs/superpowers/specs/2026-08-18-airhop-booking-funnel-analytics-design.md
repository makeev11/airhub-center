# AirHop: когортная воронка пробных занятий

Дата: 2026-08-18
Статус: согласованный рабочий дизайн

## Цель

Показать владельцу центра, как пробные записи превращаются в постоянных
учеников и первую оплаченную PaymentExpectation, не смешивая когорты разных
месяцев и источников.

## Единица и период отчёта

Единица воронки — сохранённый `Booking` с `visit_kind = trial`. Когортный месяц
определяется по `Booking.created_at` в часовом поясе организации. Отчёт содержит
шесть календарных когортных месяцев до текущего включительно.

Этапы считаются как независимо наблюдаемые подмножества исходной когорты:

1. пробная запись создана;
2. запись когда-либо подтверждена;
3. текущее исправленное состояние посещаемости — `present`;
4. из этой пробной записи создано постоянное зачисление;
5. первая PaymentExpectation этого зачисления оплачена.

Этапы не принуждаются искусственно к вложенности. Например, сотрудник может
перевести ребёнка в постоянные до отметки посещаемости; отчёт показывает
фактические данные и долю каждого этапа от исходной когорты.

## Источники истины

- `airhop_bookings` — когорта, канал источника и стабильная ссылка занятия;
- append-only booking events — исторический факт подтверждения после
  последующей отмены;
- `airhop_lesson_attendance` — текущая исправляемая отметка посещения;
- `airhop.enrollment.created_from_trial.v1` — точная связь пробного занятия,
  зачисления и первой оплаты;
- `airhop_payment_expectations` — текущий authoritative статус первой оплаты;
- `airhop_lesson_occurrences` и `airhop_branches` — филиал сохранённого занятия.

Новые события перевода сохраняют `sourceBookingId`. Старые события читаются по
совместимой стабильной тройке `childId + recurrenceRuleId + originalDate`.

## Серверный контракт

Защищённый staff endpoint
`GET /api/airhop/staff/v1/booking-funnel-analytics` возвращает:

- локальную дату расчёта;
- шесть когортных месяцев;
- количество записей на каждом этапе;
- суммы первых оплаченных ожиданий отдельно для каждой валюты;
- совместные сегменты `sourceChannel + branch`, из которых клиент может
  безопасно строить фильтры без повторного доступа к персональным данным.

Ответ не содержит имён, телефонов, дат рождения, booking id или child id.

## Интерфейс

Экран `/booking/analytics` получает вкладку «Воронка». Пользователь выбирает
когортный месяц, источник и филиал. Карточки показывают количество и долю каждого
этапа от пробных записей; суммы первой оплаты выводятся отдельными строками по
валютам. Ни одна смешанная валютная сумма не создаётся.

## Не входит в срез

- маркетинговая атрибуция за пределами сохранённого source channel;
- прогноз конверсии и LTV;
- разовые занятия;
- баланс абонемента, возвраты, скидки и частичные оплаты;
- экспорт и сравнение с банковской выпиской.
