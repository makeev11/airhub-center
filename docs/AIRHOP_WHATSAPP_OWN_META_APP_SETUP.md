# Подключение собственного WhatsApp Cloud API к AirHop Center

Статус: инструкция, мастер подключения и hosted WhatsApp Cloud adapter готовы.
Ввод реквизитов включается только в окружении, где запущен Channel Gateway и
задан публичный HTTPS Callback URL; до этого мастер остаётся доступен как
пошаговая инструкция, но не принимает секреты. Перед объявлением production
доступности конкретного развёртывания нужно пройти реальный сквозной тест номера.

Эта инструкция предназначена для владельца или администратора центра. В ней
подключается **официальный WhatsApp Business Platform Cloud API** через
Meta-приложение, принадлежащее самому центру.

AirHop не просит доступ к чужому Meta Business через общее приложение. Поэтому
такой способ подходит для первых подключений без App Review приложения AirHop.
Meta при этом всё равно может потребовать проверку бизнеса, подтверждение
отображаемого имени, настройку оплаты и соблюдение правил WhatsApp.

Номер поддержки AirHub HQ и номера партнёрских AirHop Center — независимые
подключения. Для центра используются его собственные Meta Business Portfolio,
Meta-приложение, WABA и номер; существующий номер AirHub HQ не переносится и не
меняется.

## Что получится

После настройки:

- родители пишут на WhatsApp-номер центра;
- сообщения появляются в общей клиентской переписке AirHop Center;
- сотрудники и Гермес отвечают из AirHop Center;
- компьютер с AirHop Center не обязан принимать webhook и иметь публичный IP;
- токен и App Secret хранятся зашифрованными и не показываются повторно.

Официальные исходные точки Meta:

- [Meta for Developers — приложения](https://developers.facebook.com/apps/);
- [Meta Business Settings — системные пользователи](https://business.facebook.com/settings/system-users/);
- [WhatsApp Cloud API](https://developers.facebook.com/docs/whatsapp/cloud-api/);
- [актуальные тарифы WhatsApp Business Platform](https://whatsappbusiness.com/products/platform-pricing/);
- [официальная коллекция WhatsApp Cloud API](https://www.postman.com/meta/whatsapp-business-platform/collection/wlk6lh4/whatsapp-cloud-api).

Названия пунктов Meta иногда меняются. Ориентируйтесь на слова **WhatsApp**,
**API Setup**, **Configuration**, **System Users** и **WhatsApp Accounts**.

## Перед началом

Понадобятся:

1. Доступ владельца или администратора к AirHop Center.
2. Meta Business Portfolio центра и права полного управления.
3. Meta Developer Account человека, который выполняет подключение.
4. Номер, способный принять SMS или голосовой код Meta.
5. Примерно 20–40 минут без закрытия вкладок Meta.

В первой версии AirHop используйте отдельное Meta-приложение для каждого
подключаемого WhatsApp-номера. У Meta Callback URL задаётся на уровне приложения,
поэтому повторное использование одного приложения для нескольких подключений
может перезаписать уже работающий webhook.

Если номер уже используется в обычном WhatsApp или WhatsApp Business на
телефоне, Meta предложит доступный для этого аккаунта сценарий. Используйте
официальный режим coexistence, если он показан. Если его нет, номер потребуется
удалить из мобильного WhatsApp перед регистрацией в Cloud API. Историю пустого
аккаунта переносить не требуется.

Не используйте QR-подключение через неофициальные WhatsApp Web-библиотеки. Оно
не является Cloud API, зависит от активной телефонной сессии и повышает риск
отключения номера.

## Шаг 1. Создайте приложение Meta

1. Откройте [Meta for Developers](https://developers.facebook.com/apps/).
2. Нажмите **Create app**.
3. Выберите сценарий, связанный с WhatsApp Business Messaging. В текущем
   интерфейсе он может называться **Connect with customers through WhatsApp**.
4. Выберите Business Portfolio именно этого центра.
5. Завершите создание приложения и откройте продукт **WhatsApp**.

Запишите **App ID**. App Secret пока не отправляйте и не вставляйте в чаты.

## Шаг 2. Добавьте WhatsApp-номер

1. В приложении Meta откройте **WhatsApp → API Setup**.
2. Создайте или выберите WhatsApp Business Account (WABA) центра.
3. Нажмите **Add phone number** и укажите публичное название центра, категорию
   и номер.
4. Подтвердите номер по SMS или голосовому звонку.
5. Если Meta просит PIN двухэтапной проверки, задайте и сохраните его в
   менеджере паролей центра.

На странице API Setup найдите и сохраните:

- **WhatsApp Business Account ID (WABA ID)**;
- **Phone Number ID** — это не сам номер телефона;
- **App ID**.

Все три значения состоят из цифр. Сам номер в формате `+55…` вместо Phone
Number ID не подходит.

## Шаг 3. Создайте постоянный System User Token

Временный токен из API Setup удобен только для короткой проверки и истекает.
Для постоянной работы нужен System User Token.

1. Откройте **Business Settings → Users → System Users**.
2. Создайте системного пользователя, например `AirHop WhatsApp Gateway`, с
   административной ролью.
3. Нажмите **Assign assets** и дайте ему доступ к созданному Meta-приложению и
   WhatsApp Business Account.
4. Нажмите **Generate new token** и выберите приложение центра.
5. Выберите максимальный доступный срок действия, предпочтительно постоянный.
6. Добавьте разрешения:
   - `whatsapp_business_management`;
   - `whatsapp_business_messaging`.
7. Скопируйте токен сразу: Meta больше не покажет его полностью.

Не отправляйте токен сотрудникам в мессенджерах. Вставьте его только в закрытое
поле мастера AirHop Center.

## Шаг 4. Передайте реквизиты AirHop

В AirHop Center откройте:

**Настройки → Каналы связи → Добавить канал → WhatsApp → Собственное
Meta-приложение**.

Введите:

- App ID;
- App Secret из **App settings → Basic**;
- WABA ID;
- Phone Number ID;
- постоянный System User Token.

Выберите общий клиентский канал или филиал. AirHop проверит токен через Meta,
подтвердит принадлежность Phone Number ID выбранному WABA и сохранит секреты в
зашифрованном хранилище. Секреты не входят в историю сообщений и не
возвращаются обычным API настроек.

## Шаг 5. Подключите webhook

После проверки AirHop покажет два значения:

- **Callback URL**;
- **Verify Token**.

1. Вернитесь в приложение Meta.
2. Откройте **WhatsApp → Configuration**.
3. В блоке webhook нажмите **Edit**.
4. Вставьте Callback URL и Verify Token без пробелов в начале и конце.
5. Нажмите **Verify and save**.
6. В списке webhook fields подпишитесь как минимум на **messages**.
7. Вернитесь в AirHop и нажмите **Я сохранил webhook**.

Callback URL уже содержит идентификатор подключения. Не заменяйте его адресом
локального компьютера и не убирайте окончание URL.

## Шаг 6. Проверьте сообщение

1. Напишите на номер центра с другого личного WhatsApp-номера.
2. Не используйте для теста тот же номер, который подключён как бизнес-номер.
3. Дождитесь появления сообщения в клиентской переписке AirHop Center.
4. Ответьте из AirHop Center.

После входящего сообщения открывается 24-часовое окно обслуживания, в котором
можно отвечать обычным текстом. Первое сообщение от бизнеса или сообщение после
закрытия этого окна отправляется только через заранее одобренный шаблон Meta.

## Тестирование, срок работы и оплата

У собственного подтверждённого номера нет отдельного «пробного срока», после
которого интеграция сама выключится. Для постоянной работы нужны действующий
System User Token, активный WABA, корректный способ оплаты, нормальное качество
номера и работающий AirHop WhatsApp Gateway. Временный токен из **API Setup** для
этого не подходит: он предназначен для короткой проверки и истекает.

Meta тарифицирует доставленные сообщения по рынку получателя и категории.
Обычные service-ответы в открытом 24-часовом окне не тарифицируются; исходящие
marketing, authentication и часть utility-сообщений могут тарифицироваться по
соответствующей категории. Точные ставки меняются, поэтому перед запуском
проверьте [официальную страницу тарифов](https://whatsappbusiness.com/products/platform-pricing/),
выбрав рынок и валюту. Если AirHop в будущем введёт отдельную плату за hosted
gateway, она должна показываться отдельно и не смешиваться со счётом Meta.

## Согласие родителей и правила сообщений

До первого исходящего сообщения центр должен получить явное согласие родителя
на связь через WhatsApp и сохранить источник этого согласия. В сообщениях должно
быть понятно, какой центр пишет и как перейти к сотруднику. Просьбу прекратить
сообщения нужно выполнять сразу; рассылки без согласия и неофициальная массовая
автоматизация недопустимы. Актуальные требования опубликованы в
[WhatsApp Business Messaging Policy](https://business.whatsapp.com/policy/).

Подключение считается готовым только когда карточка показывает **Работает** и
в ней появилась свежая дата последней проверки.

## Частые проблемы

### Не приходит SMS

- проверьте код страны и номер;
- отключите блокировку сервисных SMS у оператора;
- попробуйте голосовой звонок;
- не запрашивайте код много раз подряд — Meta включает временный cooldown;
- убедитесь, что номер удалён из мобильного WhatsApp, если coexistence не был
  предложен.

### AirHop пишет, что токен недействителен

- не используйте короткий временный токен из старой вкладки API Setup;
- проверьте, что System User получил оба WhatsApp-разрешения;
- повторно назначьте ему приложение и WABA в **Assign assets**;
- создайте новый токен и повторите подключение.

### Phone Number ID не принадлежит WABA

Вы, вероятно, скопировали данные из разных WhatsApp Business Accounts или
вставили сам номер телефона. Скопируйте оба ID с одной страницы API Setup.

### Meta не принимает Callback URL или Verify Token

- скопируйте оба значения заново из одного подключения AirHop;
- проверьте отсутствие пробелов;
- не используйте Verify Token от другого номера или прежней попытки;
- убедитесь, что подключение не было удалено и создано заново.

### Webhook сохранён, но сообщений нет

- в Meta подпишитесь на поле **messages**;
- проверьте, что пишете с другого номера;
- откройте карточку подключения: ошибка адаптера и время последнего heartbeat
  показываются там;
- не создавайте второй Callback URL для того же Meta-приложения: у приложения
  должен оставаться один актуальный webhook AirHop.

### Входящие работают, а ответ не отправляется

- проверьте, что 24-часовое окно ещё открыто;
- для нового диалога выберите одобренный template;
- проверьте способ оплаты, качество номера и статус шаблона в WhatsApp Manager.

## Обслуживание подключения

- При отзыве System User Token создайте новый и используйте действие
  **Обновить доступ** в карточке подключения.
- Не удаляйте Meta-приложение, WABA или системного пользователя, пока канал
  активен.
- При замене токена не создавайте новый канал: обновление существующего
  подключения сохраняет маршрутизацию и историю переписки.
- При передаче управления центром передайте доступ к Business Portfolio и
  ротируйте App Secret и System User Token.
- Отключая номер, сначала приостановите канал в AirHop, дождитесь завершения
  исходящих сообщений и только затем удаляйте его в Meta.

## Контрольный список готовности

- [ ] Meta-приложение принадлежит Business Portfolio центра.
- [ ] Номер подтверждён и виден в WhatsApp Manager.
- [ ] System User имеет приложение и WABA в Assign assets.
- [ ] Токен содержит `whatsapp_business_management` и
      `whatsapp_business_messaging`.
- [ ] AirHop подтвердил WABA ID и Phone Number ID.
- [ ] Callback URL и Verify Token сохранены в Meta.
- [ ] Webhook field `messages` включён.
- [ ] Карточка AirHop показывает «Работает».
- [ ] Входящее и ответ из AirHop проверены на двух разных номерах.
